### WWMM 사용자 안내 및 주의사항 ###

#### 운영체제 버전 안내 ####
본 프로그램은 Windows 10 이상 환경에서 테스트 및 개발되었습니다.
Windows 10, 11 환경에서의 사용을 권장하며,
그 이하(Windows 7/8/8.1 등)에서는 일부 기능이 정상적으로 동작하지 않을 수 있습니다.

1. 설치/압축 해제 위치
반드시 C:\Program Files, C:\Windows 등 시스템 폴더가 아닌
바탕화면, 내 문서, 다운로드 폴더, D:\Games\WWMM 등 일반 폴더에 압축 해제 및 설치하세요.

시스템 폴더에 설치하면 권한 문제로 정상 동작하지 않을 수 있습니다.

2. 일반 권한으로 실행
WWMM 프로그램은 반드시 “일반 권한(더블클릭)”으로 실행하세요.

“관리자 권한으로 실행”은 하지 마세요!
(관리자 권한 실행 시 드래그 앤 드롭 등 주요 기능이 작동하지 않습니다.)

3. 심볼릭 링크 및 관리자 권한 안내
모드 적용/해제 시 심볼릭 링크를 생성해야 하므로
자동으로 “관리자 권한 요청(UAC)” 창이 뜹니다.

이때 반드시 “예(허용)”를 눌러야 정상적으로 모드가 적용/해제됩니다.

직접 “관리자 권한”으로 WWMM을 실행할 필요는 없으며,
모드 작업이 필요할 때만 권한 요청이 자동으로 이루어집니다.

4. 백신/윈도우 디펜더 예외 설정
본 프로그램(특히 직접 만든 exe 파일, 심볼릭 링크 등)은
일부 백신/Windows Defender에서 “오탐지”로 차단 또는 삭제될 수 있습니다.

반드시 WWMM 설치 폴더 전체(예: C:\Games\WWMM\ 등)를
백신/Defender 예외 목록에 추가해 주세요.

(예외 설정 방법은 ‘백신 예외 설정법.txt’ 참고 또는
Windows Defender 예외 설정 공식 안내 참고)

5. 아이콘 관련 안내
프로그램 실행 시 작업표시줄/타이틀바에 커스텀 아이콘이 정상 표시되면 제대로 동작하는 것입니다.

탐색기(폴더 창)에서 EXE 아이콘이 바뀌지 않는 현상은
윈도우의 “아이콘 캐시” 문제이며,
재부팅/EXE 이름 변경 등으로 해결됩니다.

6. Ps.주의사항
- 모드를 적용한 뒤 경로 및 WWMM의 폴더 이름을 바꾸지 마세요. 모드 적용 후 경로를 바꾸시면 모드 해제를 할 수 없습니다.
- 모드를 적용한 뒤 경로 및 WWMM의 폴더 이름을 바꿔버리신 경우 수작업으로 XXMI/WWMI/Mods 안에 있는 해당 모드를 지우신후 WWMM - Wuthering Waves Mod Manager에서 해제하기를 하시면 다시 정상적으로 이용 가능
하게 됩니다.
- 게임을 실행한 뒤 모드를 변경하시거나 해제 하셧다면 F10을 누르셔야 반영이 됩니다.


7. 기타 FAQ
실행/모드 적용이 안 될 때
→ 폴더 위치를 바꿔보세요(시스템 폴더 X)
→ 백신 예외 등록 여부 확인
→ EXE 이름 잠깐 바꿨다가 다시 시도

모드 적용 후 게임 실행/실행 중 모드 전환 시
→ 게임 및 런처 재시작을 권장

문의/버그 신고
→ 깃허브 이슈 또는 배포 페이지에서 문의해주세요
